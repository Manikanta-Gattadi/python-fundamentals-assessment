# python-fundamentals-assessment
# Python Fundamentals – Internship Assessment

## About the Project

This repository contains my solutions to the Python Fundamentals Programming Assessment assigned as part of the Learn Depth Academy Python Internship.

The assessment focuses on understanding and implementing basic Python programming concepts through six practical programming problems. Each question is implemented in a separate Python file to maintain clarity and organization.

## Programming Questions

The repository includes solutions to the following six problems:

| No. | Program | Description |
|---|---|---|
| 1 | Even or Odd | Checks whether a given integer is even or odd. |
| 2 | Largest of Three Numbers | Finds the largest among three user-entered numbers. |
| 3 | Sum of Numbers from 1 to N | Calculates the sum of natural numbers up to N using a loop. |
| 4 | Count Vowels in a String | Counts the vowels present in a given string. |
| 5 | Reverse a String | Reverses a user-provided string. |
| 6 | Function-Based Calculator | Performs addition, subtraction, multiplication and division using separate functions. |

## How to Run the Programs

**Step 1:** Install Python 3 on your computer.

**Step 2:** Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 3:** Navigate to the project directory:

```bash
cd python-assessment
```

**Step 4:** Run any program using Python:

```bash
python question1_even_odd.py
```

Replace the filename with the program you want to execute.
